Rekapitulasi Input Data

Halaman ini menampilkan rekapitulasi input data yang dilakukan oleh staf dan guru. Data rekapitulasi ini dapat digunakan oleh pengelola sekolah untuk memantau aktivitas input data dan kinerja dari staf dan guru.

    Adapun kategori input data yang dicatat oleh aplikasi yaitu:
  • Pendataan Calon Siswa
  • Pendataan Siswa
  • Rencana Program Pembelajaran
  • Presensi Harian
  • Presensi Pelajaran
  • Penilaian
  • Komentar Nilai Rapor
  • Catatan Siswa
