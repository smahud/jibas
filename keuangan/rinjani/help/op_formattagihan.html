Kode Awalan Nomor Tagihan

Halaman ini digunakan untuk mengatur kode awalan nomor tagihan untuk pembuatan tagihan melalui Payment Gateway di aplikasi JIBAS Jendela Sekolah.

Kode awalan ini berguna untuk membedakan nomor tagihan untuk setiap departemen di sekolah. Dengan menggunakan kode awalan yang berbeda, pengguna dapat dengan mudah mengelola dan mengidentifikasi tagihan berdasarkan departemen masing-masing.

Kode awalan harus berupa 1 digit angka yang unik untuk setiap departemen. Misalnya, Anda dapat menggunakan '1' untuk Departemen SMA, '2' untuk Departemen SMP, dan seterusnya.
